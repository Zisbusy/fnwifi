# fnwifi
## 主要功能
在飞牛中利用无线网卡开启一个无线热点
<img width="1126" height="666" alt="image" src="https://github.com/user-attachments/assets/65d7cd72-89ed-4df1-bfb5-e70601a46650" />

## 兼容架构
- X86-64
- ARM

## 特点
1. 仿照飞牛应用页面,更加整体化
2. 实现夜间模式的自动切换
3. 自带静态二进制文件,减少对系统打扰
4. 简单的终端监控与管理
